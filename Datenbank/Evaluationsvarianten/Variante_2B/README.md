# Variante 2B – Few-Shot

In jeden der zwölf Merkmalsordner kommen zwei bis fünf manuell ausgewählte
Referenzbilder; Ziel sind drei. Das jeweilige Bild aus Variante 2A muss enthalten
sein.

Namensbeispiel: `REF_LSF_SerieX_021_B02.jpg` (fiktiv, nicht aus der Testserie).
Die Herkunft wird in `referenzen.csv` dokumentiert.
